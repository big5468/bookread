# 馆间 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 实现需求附件中完整的本地优先 Android 阅读、自习、卡片和可选 AI 闭环。

**Architecture:** 单 app 模块，data/domain/ui 分包；Room 为业务唯一持久化来源。UI 通过 ViewModel 和 Repository 读写数据，领域计算保持纯 Kotlin。

**Tech Stack:** Kotlin、Compose、Material 3、Navigation Compose、Room、Coroutines/Flow、DataStore、Keystore、Retrofit、Gradle Kotlin DSL。

**Spec:** docs/superpowers/specs/2026-09-10-library-design.md（用户已确认）

## Global Constraints

- 最低 Android API 26；中文、浅色与深色、四个底栏目的地。
- 核心离线，无账号、同步、后台 AI 或馆藏网络查询。
- 每次 AI 上传确认，结果预览后显式保存；Key 仅加密保存且不记录日志。
- 当前目录为空仓库，按用户要求直接在当前项目创建；不另建目录或覆盖用户文件。
- 日期为 ISO 本地日、时间为 UTC 毫秒；周一开始，跨日专注拆分。
